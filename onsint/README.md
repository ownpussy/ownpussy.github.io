# ONSINT

Phone OSINT console. Open the GitHub Pages URL in Safari, then Share → Add to Home Screen.

Public sources only. Username checks may pass through a public CORS proxy because phone browsers block direct requests to most sites. Do not type secrets into the search box.

- Usernames: public account checks plus manual profile links
- Email: Gravatar, GitHub commit search, mail-domain DNS, handoff to emailosint.org
- Domains: Cloudflare DNS-over-HTTPS, crt.sh, RDAP
- IPs: ipwho.is and Shodan InternetDB (no API key, no private Shodan query)
